Dashboard

A small personal desktop app for Windows that keeps everyday information in one window.

Dashboard shows:

  • countdowns to upcoming dates, and "days since" reminders for chores;
  • game times and scores for followed sports teams;
  • the local weather forecast;
  • a summary of unread Gmail messages: sender, subject, a one-line preview, and time received.
How it uses Gmail. With the owner's permission, Dashboard uses read-only access (gmail.readonly) to list unread inbox messages and show their sender, subject, preview and time. It never sends, deletes, labels or marks mail as read. The data stays on the owner's own computer and is not shared with anyone. See the privacy policy for details.

Dashboard is a personal project. It runs only on its owner's PC and is not offered as a service to the public.
