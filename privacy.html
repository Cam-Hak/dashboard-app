Dashboard Privacy Policy

Effective October 12, 2026

Dashboard is a personal desktop app that runs on its owner's Windows PC. This policy explains what it does with data from Google when the owner connects a Gmail account.

Data Dashboard accesses

Dashboard asks for one Google permission, read-only Gmail access (https://www.googleapis.com/auth/gmail.readonly). With it, Dashboard reads:

  • the IDs of inbox messages that match the owner's filter (by default, unread mail outside Promotions and Social);
  • for the newest of those messages (15 by default): the sender, subject, date, Gmail's short preview snippet, and whether the message is unread;
  • the account's email address, so that links open the right mailbox.

Dashboard does not read full message bodies or attachments. It never sends, deletes, labels or archives mail, and never marks messages as read.

How the data is used

The data is used only to show the owner a list of unread messages in the Dashboard window on their own computer. It is not used for advertising, profiling, or training any machine-learning or AI model, and it is not sold.

Where the data is stored

  • Gmail data travels only between the owner's computer and Google's servers. Dashboard has no server of its own.
  • To show the last known inbox summary at startup or while offline, Dashboard may keep it in a local file on the owner's computer (%APPDATA%\dashboard\cache\email.json). The owner can turn this off.
  • The sign-in token and app credentials are stored in Windows Credential Manager on the owner's computer.

Sharing

Dashboard does not share, transfer or disclose Google user data to anyone.

Google API Services User Data Policy

Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Click Disconnect in Dashboard's Email panel to delete the stored sign-in and the cached inbox summary.
  • Access can also be revoked at any time at myaccount.google.com/permissions.
  • Uninstalling Dashboard and deleting the %APPDATA%\dashboard folder removes all of its local data.

Changes

If Dashboard's use of Google data changes, this page will be updated first and the effective date above revised.
